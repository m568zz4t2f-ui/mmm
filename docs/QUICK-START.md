# Wolf Tide 1.3 — Quick Start

Open a Combined preset, set Mix modestly, then adjust the delay and reverb Amount controls. SEND removes dry audio for an aux/return. Main grey controls edit Delay A; blue controls edit Reverb A. Each side's processing menu explicitly selects Legacy or Tide 1.3.

EDIT DELAY / EDIT REVERB opens the scrollable 1.3 panel. Choose Delay A/B or Reverb A/B in its page menu. B slots have independent machines and controls and start disabled. ROUTING opens Series, Parallel or Frequency split, the crossover, cross feedback and output trim. Only controls implemented for the current machine are offered. Legacy mode retains the original deeper editor and old processing.

Choose ON to stop/resume fresh excitation while stored tails finish. HOLD retains reverb feedback; granular Freeze retains its own recorded capture. CLEAR TAILS fades output and empties stored audio without changing settings. Tails continue only while the DAW processes audio.

SYNC follows host BPM when available. Routing includes fallback/manual tempo; Delay B has its own sync/rhythm. Dry audio remains immediate; pitch and grain windows add wet latency. Main times reach 8 seconds; reverse/multitap readers can span 16 seconds.

BROWSE and the side `...` buttons open search, Factory/User, Favorites and Recent collections. A side preset changes that family independently. LOCK protects both slots of its family during combined recall. LOCK MIX also protects B returns. LOCK ROUTE protects the routing, split and cross-feedback values. Factory/User/Modified labels describe the saved parameter identity; editing advanced controls marks a preset modified.

UNDO LOAD reverses the last preset load. A/B stores a reference on its first click and swaps states afterward. Projects store the actual parameter values, revisions, locks and independent preset names. Old sessions and presets retain Legacy processing with B off until explicitly upgraded. Existing program indices remain stable.

Output calibration uses fixed per-machine trims, with a soft emergency ceiling on wet-active output. It does not automatically match your performance's loudness. Monitor levels and check wide settings in mono, especially with high feedback, long tails or HOLD. The output trim can boost a transparent dry path above 0 dBFS. The animated artwork illustrates controls/activity; it is not a frequency or waveform analyzer.
