# Wolf Tide 1.2.0

This update adds a boutique charcoal/ocean-blue interface and a shared searchable preset browser with Factory, User, Favorites and Recent collections, instrument filters, direct user saving and independent Undo Last Load / A-B comparison. The original 16 program slots remain, followed by 32 musical and 4 utility recipes. Each of the 9 delay choices and 11 reverb choices has two side starters.

New delay choices: Diffusion, four-head Granular Pitch (two complementary voice pairs) and Lo-Fi. Existing Digital/Tape/Analog/Pattern/Reverse/Pitch remain; new starting points favor conventional quarter/dotted/slap sounds, clean Digital defaults and Fixed Harmony. Advanced controls add independent A/B timing, feedback and B level, 2/4/8-tap patterns, input swell, manual tempo and tap tempo. A/B represents the stereo A and B paths, not two complete stereo delay processors.

New reverb choices: Chamber, Cloud Ensemble, Halo Shimmer, Glint, Studio Plate, Studio Hall and Studio Bloom. These use dedicated early/diffusion/feedback structures and model-specific processing; Halo and Studio Plate use the coupled tank, while the other new models use an eight-line orthogonal feedback network. Halo and Glint have their own filtered pitch-regeneration path. Diffusion, Size, Bloom Attack and Pitch Regeneration are available in Advanced. Spring, Resonator and spectral Aurora are not included.

Fixes: coalesced delay and predelay targets; fixed-length modern pitch windows and gradual pitch-filter changes; same-rate host preparation retains tails; reverb preset scope no longer changes delay rhythm or ratio. Float defaults never overwrote Air Throw Fixed Harmony; that earlier reported issue was withdrawn.

Compatibility: the original 44 parameter positions/IDs and selector normalization remain. Sixteen extension parameters are appended. Old states and version-1 portable presets reset extension defaults. Delay/reverb sound versions are independent. The retained original engines matched the old binary fixture sample for sample in a six-scenario Linux comparison at 8 kHz; this is a bounded fixture, not exhaustive compatibility proof. Preset version 2 validates complete scope, finite in-range values and unique IDs before applying. Session tempo, send and output remain session controls while browsing. Locks can yield partial recall.

Optimization: affected-group coefficient updates; no whole parameter structure copied per sample; skip inactive weight work and unnecessary swell/independent-B calculations; static faceplate cache; hidden editor timers stop; only needed pitch voices and active tanks process. New-model outgoing tails fade over two seconds, retiring faster during rapid browsing. Legacy tank tails retain their prior behavior. No automatic render-quality switching.

Quality limits: these are original published-principle implementations, not recovered proprietary code or measured hardware clones. Classic dual-head pitch can still smear transients and texture chords; the granular model is intentionally more textured. Tape/Analog are musical models, not component-accurate simulations. Final approval of instrument voicing needs listening on the user's recordings. Synthetic tests and a compile do not establish subjective superiority. No claim that every new sound uses less CPU than every old sound is made.

Distribution: normal Mac package installs AU, VST3 and Standalone plus corresponding source, pinned JUCE, licenses and documentation. Actual validation, architecture and signing status are recorded separately. Local installation preserves previous user bundles in install-backups. Close/reopen the host and rescan if it retains a loaded old plug-in.
